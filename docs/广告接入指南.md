# 广告接入指南

> 本项目已完成广告 SDK 抽象层，当前挂的是本地模拟实现（无任何 SDK 依赖）。
> 本文说明现有架构、频控策略，以及接入真实 SDK 的完整步骤。

## 一、现有架构（v0.3.2 起）

```
业务代码（弹窗/页面）
    ↓ 只调用
AdManager（分发 + 频控）
    ↓ 委托给
AdApi（抽象接口） ← StubAdApi（本地模拟，当前默认）
                    ← XxxAdApi（真实 SDK，接入时新建）
```

| 文件 | 职责 |
|---|---|
| `ads/AdApi.kt` | 广告位枚举 `AdPlacement`、结果回调 `AdResult`、SDK 抽象接口 |
| `ads/AdManager.kt` | Provider 分发 + 频控（冷却/每日上限，自然日重置），`setProvider()` 可热替换 |
| `ads/StubAdApi.kt` | 本地模拟：弹对话框假播 3 秒，看完发奖，可中途跳过 |

**已接入的业务闭环**：专注完成掉落弹窗 →「看广告再领 1 张」（`REWARD_EXTRA_CARD` 广告位）→ 看完 → 按 25 分钟档再掉一张卡 → 刷新统计/收藏条/成就。

## 二、广告位与频控

| 广告位 | 类型 | 冷却 | 每日上限 | 状态 |
|---|---|---|---|---|
| `REWARD_EXTRA_CARD` | 激励视频 | 30 分钟 | 5 次 | ✅ 已接（专注完成弹窗） |
| `INTERSTITIAL_SESSION_END` | 插屏 | 60 分钟 | 3 次 | 预留 |
| `SPLASH` | 开屏 | - | 1 次 | 预留 |
| `HOME_BANNER` | 横幅 | - | 不限 | 预留（需 View 容器，接口后续扩展） |

频控数据存 `SharedPreferences(focus_ads)`，按自然日自动重置；改策略只动 `AdPlacement` 枚举字段，业务代码不用改。

## 三、接入真实 SDK 步骤

以穿山甲（GroMore）或 AdMob 为例，步骤相同：

**1. 加依赖**（`app/build.gradle.kts`）

```kotlin
// 示例：穿山甲
implementation("com.pangle.global:ads-sdk:6.x.x")
// 或 AdMob
implementation("com.google.android.gms:play-services-ads:23.x.x")
```

**2. 实现 AdApi**

```kotlin
class GromoreAdApi : AdApi {
    override val name = "GroMore"

    override fun initialize(context: Context) {
        // SDK init + 合规设置（同意状态、未成年人模式等）
    }

    override fun isReady(placement: AdPlacement) =
        // 查询对应广告位缓存是否 ready
        true

    override fun load(placement: AdPlacement) { /* 预加载 */ }

    override fun show(activity: Activity, placement: AdPlacement, onResult: (AdResult) -> Unit) {
        // 展示；内部把各 SDK 回调映射到 AdResult：
        //   完整看完 → AdResult.Rewarded
        //   中途关闭 → AdResult.ClosedEarly
        //   加载/渲染失败 → AdResult.Failed(reason)
    }
}
```

**3. 创建 Application 并替换 Provider**

```kotlin
class FocusApplication : Application() {
    override fun onCreate() {
        super.onCreate()
        AdManager.setProvider(GromoreAdApi())
        AdManager.init(this)
    }
}
// AndroidManifest.xml 的 <application android:name=".FocusApplication">
```

**4. 完事**。业务代码（`MainActivity.showDrop` 等）零改动，频控自动生效。

## 四、注意事项

- **回调线程**：接口约定 `onResult` 在主线程回调；第三方 SDK 回调不在主线程时，实现里要 `Handler(Looper.getMainLooper()).post { ... }` 包一层
- **提前预加载**：激励视频建议在专注开始时 `AdManager.init` 后调用 `load()`，展示时才不空转（当前 Stub 不需要）
- **ProGuard**：真实 SDK 需加混淆规则（各官方文档有现成的拷进 `proguard-rules.pro`）
- **合规**：国内上架需接 SDK 前完成隐私弹窗 + 同意状态上报；AdMob 需配 `AD_APP_ID`（manifest meta-data），否则直接闪退
- **未成年人模式**：国内渠道要求可一键关闭所有广告位，可在 `AdManager` 加全局开关，`isAvailable` 统一返回 false
