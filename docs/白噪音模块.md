# 白噪音模块（XMSLEEP 式）

> v0.9.5 引入。架构参考开源白噪音应用 [XMSLEEP](https://github.com/Tosencen/XMSLEEP)（MIT）：
> **多声景同时叠加混音 + 分类声音库 + 每声音独立音量 + 无缝循环**；
> 声音本体沿用本项目的**零资源程序化合成**路线，未拷贝 XMSLEEP 的任何音频素材与代码。

## 一、为什么这么设计

| 决策 | 说明 |
|---|---|
| 程序化合成（保留原路线） | 不打包任何音频资源：APK 零增量、天然无缝循环、免素材授权风险。XMSLEEP 用的是录音素材 + ExoPlayer，本模块吸收其交互模型而非存储模型 |
| 多声部混音（吸收 XMSLEEP） | 原来 5 选 1 单选；现在 18 种声景可任意组合叠加，如「雨声 + 炉火 + 猫呼噜」 |
| 单 AudioTrack + 合成线程 | 所有声部共享一条 44.1kHz 单声道 AudioTrack，线程内实时叠加，切换零重建开销 |
| 每声音独立音量（吸收 XMSLEEP） | 长按声景芯片弹出独立音量滑杆；另有作用于所有声部的主音量 |

## 二、文件结构

```
app/src/main/java/me/hebin/focus/audio/
├── AmbientSound.kt   声景目录：enum（分类 + 中文标签），playable 提供界面展示顺序
├── AmbientSynth.kt   18 种声景的程序化合成器（有状态闭包，每次调用产出一个采样）
├── AmbientPlayer.kt  混音引擎：多声部、淡入淡出、tanh 软限幅、主音量
└── AmbientPrefs.kt   偏好：多选集合 + 每声音量 + 主音量 + 旧版单选自动迁移
```

## 三、声音清单（18 种 / 六类）

| 分类 | 声景 | 合成要点 |
|---|---|---|
| 噪声 | 白噪 / 粉噪 / 棕噪 | 均匀随机 / Paul Kellet 1/f 滤波 / 泄漏积分 1/f² |
| 天气 | 雨声 / 雷雨 / 风 | 低通雨幕+雨滴瞬态 / 雨幕+快起慢落闷雷 / 阵风调制的低通噪声 |
| 自然 | 海浪 / 溪流 / 森林 / 炉火 | 布朗噪声×浪涌包络 / 水流+气泡正弦 / 风床+树叶沙沙 / 炭火+爆裂瞬态 |
| 动物 | 夜虫 / 鸟鸣 / 猫呼噜 | 4.2kHz 载波×27Hz 脉冲串 / FM 扫频音符短语 / 25Hz 颤动×呼吸包络 |
| 场所 | 咖啡馆 / 火车 | 带通人声+杯碟碰撞 / 轰鸣+轨缝双击 |
| 物品 | 时钟 / 风扇 / 键盘 | 半秒滴答交替 / 21Hz 叶片调制 / 泊松敲击（空格更沉） |

## 四、引擎要点（AmbientPlayer）

- **声部（Voice）**：`gen` 生成器闭包 + `target/cur` 增益对 + `dying` 标记；ConcurrentHashMap 存储；
- **淡入淡出**：每采样 `cur += (target - cur) * 0.0011`（τ≈20ms），开/关声音无咔哒声；
- **软限幅**：混音总线 `tanh(mix)`，多声叠加自动压峰防爆音；
- **生命周期**：引擎懒创建、常驻到会话结束（`stop()`），无声部时写静音待命（无生成器计算）；线程自收尾释放 AudioTrack，与 `stop()` 无锁竞争；
- **旧偏好迁移**：旧版单选 ordinal（前 5 位与历史声明严格对齐）→ 多选集合，一次性完成。

## 五、界面（专注页白噪音面板）

- `MaterialButtonToggleGroup`（5 选 1）→ `HorizontalScrollView + ChipGroup`（多选 Filter 芯片，横滑浏览，按分类排序）；
- 芯片勾选 = 加入混音，取消 = 淡出移除；
- **长按芯片** = 该声部独立音量弹窗（拖动实时生效）；
- 下方滑杆 = 主音量（AudioTrack 层）；面板底部有一行操作提示。

## 六、已知边界

- 程序化合成的听感目标为「氛围正确」而非「录音逼真」（零体积换来的取舍）；
- 深度专注默认雨声逻辑：仅当用户从未表达过任何选择时生效（用户明确全关过则尊重）；
- 单声道输出；`USAGE_MEDIA` 属性，锁屏继续播放、切走随碎裂停止（与会话生命周期一致）。
