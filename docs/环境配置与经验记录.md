## 二、沙箱环境搭建步骤（无 Android Studio）

```bash
# 1. 安装 JDK 17（环境自带 JDK 11，必须升级）
apt install -y openjdk-17-jdk-headless

# 2. 下载 Android 命令行工具 + Gradle
curl -L -o cmdtools.zip https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
curl -L -o gradle-8.5.zip https://services.gradle.org/distributions/gradle-8.5-bin.zip

# 3. 解压并安装 SDK 组件
mkdir -p $ANDROID_HOME/cmdline-tools
unzip cmdtools.zip -d $ANDROID_HOME/cmdline-tools
mv $ANDROID_HOME/cmdline-tools/cmdline-tools $ANDROID_HOME/cmdline-tools/latest   # 关键：目录必须叫 latest
yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# 4. 解压 Gradle 并生成 wrapper
unzip gradle-8.5.zip -d /opt
/opt/gradle-8.5/bin/gradle wrapper --gradle-version 8.5   # 在项目根目录执行

# 5. 构建
export ANDROID_HOME=<你的SDK路径>
./gradlew assembleDebug
```

## 三、踩坑记录

### 1. 网络代理
沙箱直连可能超时。环境变量里有 `HTTP_PROXY/HTTPS_PROXY`（本例 `http://127.0.0.1:18080`），curl 会自动读取；apt 需要 `-o Acquire::http::Proxy=...` 传参。**下载大文件（>100MB）时 curl 的 `--max-time` 要给足（≥900s），300s 会中途断掉（exit code 28）。**

### 2. cmdline-tools 目录名
解压后目录叫 `cmdline-tools`，必须改名（或移动）为 `cmdline-tools/latest`，否则 sdkmanager 报错：
`Could not determine SDK root` / `Error: Could not find or load main class com.android.sdklib.tool.sdkmanager.SdkManagerCli`

### 3. Gradle 下载依赖慢
Gradle 拉取 google()/mavenCentral() 依赖走系统代理即可（gradle 会读 GRADLE_OPTS / 环境变量？**实际上 Gradle 的 JVM 不读 http_proxy 环境变量**）。解决：在 `~/.gradle/gradle.properties` 里配置：
```
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=18080
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=18080
systemProp.http.nonProxyHosts=localhost|127.0.0.1
```

### 4. JDK 版本
AGP 8.x 必须 JDK 17。系统默认 java 是 11 时，构建报 `Unsupported class file major version` 或直接提示要求 17。构建前 `export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64`。

### 5. Gradle Daemon 内存
CI/沙箱内存有限时，`org.gradle.jvmargs=-Xmx2048m` 足够；若遇 OOM 再调。`--no-daemon` 在 CI 更稳（本沙箱单次构建用 daemon 也没问题）。

### 6. Kotlin 代码坑：inflate 返回 View
`layoutInflater.inflate(R.layout.item_chip, parent, false)` 返回类型是 `View`，
直接 `.apply { text = ...; isCheckable = true }` 会报 `Unresolved reference`（编译期才暴露）。
必须强转：`as com.google.android.material.chip.Chip`。CI 第一次跑就栽在这，2 分钟出结果，比本地全量拉依赖快。

### 7. Kotlin 代码坑（第二批）
- 程序化构建 UI 时 `setPadding(...)` / `LinearLayout.LayoutParams(...)` / `topMargin` 全部接收 **Int**，自定义 `dp()` 帮助函数要返回 `Int`，且参数也声明为 `Int`（`dp(16)` 传给 `dp(v: Float)` 编译不过，Kotlin 不做整数字面量自动转 Float）
- `Iterable<T>.sum { ... }` 不存在，带选择器的求和是 **`sumOf { }`**（`sum()` 只有无参版本）

### 8. GitHub Actions
- 用 `actions/setup-java@v4`（temurin 17）+ `android-actions/setup-android@v3`
- runner 自带 Android SDK，无需手动装
- 产物上传用 `actions/upload-artifact@v4`
- 每次构建约 3-5 分钟（依赖缓存后更快）

## 四、Git 仓库操作记录

仓库：`https://github.com/hebin123456/Focus`

```bash
# 首次推送（把默认分支从 main 换成 master）
git init -b master
git remote add origin https://<token>@github.com/hebin123456/Focus.git
git add . && git commit -m "..."
git push -f origin master
# 然后在 GitHub 网页/API：Settings → Branches → 默认分支改为 master → 删除 main
```

API 方式改默认分支 + 删 main：
```bash
curl -X PATCH -H "Authorization: token <TOKEN>" \
  https://api.github.com/repos/hebin123456/Focus \
  -d '{"default_branch":"master"}'
curl -X DELETE -H "Authorization: token <TOKEN>" \
  https://api.github.com/repos/hebin123456/Focus/git/refs/heads/main
```
